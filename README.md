- Тема: розробка програми для роботи з електронними таблицями (аналіз та обчислення виразів)

**Про програму**

- Електронна таблиця, у клітинках якої записуються арифметичні вирази
- Програма перевіряє синтаксис виразу і обчислює його значення
- Інтерфейс україномовний, зроблений на .NET MAUI
- Для розбору виразів використано ANTLR 4

**Операції (варіант 1)**

- `+ - * /` - бінарні операції (`/` відкидає дробову частину: `7 / 2 = 3`, `-7 / 2 = -3`)
- `mod`, `div` - евклідове ділення: остача завжди невід'ємна, `a = b * (a div b) + (a mod b)`
  (наприклад, `-7 div 2 = -4`, `-7 mod 2 = 1`)
- `+ -` - унарні операції
- `^` - піднесення до степеня
- цілі числа довільної довжини, круглі дужки, посилання на клітинки (`A1`, `B12`)

**Можливості**

- обчислення виразів у клітинках
- синтаксична перевірка з позицією помилки
- режими відображення ВИРАЗ / ЗНАЧЕННЯ
- виявлення циклічних посилань і ділення на нуль
- додавання та видалення рядків і стовпчиків
- збереження та відкриття таблиць у файлі JSON
- головне меню, кнопки, довідка

**Структура**

- `Lab1.Core` - логіка: граматика, обчислення, модель таблиці, збереження
- `Lab1` - інтерфейс програми
- `Lab1.Tests` - модульні тести
